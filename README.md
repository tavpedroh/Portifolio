# 💻 Pedro Henrique - Portfólio de Desenvolvimento Front-end

> O projeto que você está vendo demonstra minhas habilidades em desenvolvimento Front-end moderno, com foco em modularidade, experiência do usuário (UX) e performance.

## 🌟 Objetivo do Projeto

Este portfólio foi criado com um objetivo duplo:
1.  **Apresentação:** Servir como meu principal cartão de visitas profissional, destacando meus **projetos** e minha **trajetória de aprendizado** em Sistemas de Informação.
2.  **Demonstração Técnica:** Mostrar proficiência na construção de aplicações **Single Page Applications (SPA)** utilizando a stack moderna de Front-end.

## 🚀 Tecnologias Utilizadas

Este projeto foi construído utilizando as seguintes ferramentas e bibliotecas principais:

| Categoria | Tecnologia | Por que escolhemos? |
| :--- | :--- | :--- |
| **Framework Principal** | **React** | Essencial para componentização e construção de interfaces dinâmicas e reativas. |
| **Build Tool** | **Vite** | Utilizado para inicialização rápida e um ambiente de desenvolvimento performático (Fast Refresh). |
| **Roteamento** | `react-router-dom` | Gerenciamento de rotas e navegação fluida entre as páginas (SPA). |
| **Estilização** | CSS Puro / Variáveis CSS | Demonstração de habilidades em CSS, mantendo o código limpo e coeso com um tema **Dark Mode Minimalista**. |
| **Controle de Versão** | Git & GitHub | Prática de versionamento e trabalho colaborativo (se aplicável). |

## 📁 Estrutura do Projeto

A organização das pastas segue um padrão modular para garantir escalabilidade e fácil manutenção:

src/ ├── assets/ # Imagens, ícones e fontes estáticas. ├── components/ # Componentes reutilizáveis (Navbar, Footer, CardProject). ├── data/ # Dados mockados dos projetos e da trajetória. ├── pages/ # Componentes que representam rotas principais (Home, About, Projects). └── styles/ # Estilos globais e variáveis de tema.

## 🌐 Funcionalidades e Seções

O portfólio é dividido nas seguintes áreas:

| Seção | Foco Principal | Destaque Técnico |
| :--- | :--- | :--- |
| **Home** | Apresentação imediata e "Call to Action" (CTA). | Design Responsivo e Tema |
| **Sobre Mim** | Detalhamento da minha **Trajetória de Aprendizado** (Acadêmica, Cursos e Habilidades) | Uso de Componentes para Timeline e Tags |
| **Projetos** | Galeria com meus melhores trabalhos, linkando para repositórios e demos. | Reutilização de Componente (`CardProject`) |
| **Contato** | Formulário de contato e links diretos para redes profissionais. | Gerenciamento de Estado Básico (`useState`) |

## 🛠️ Como Executar Localmente

Siga estas etapas para ter uma cópia do projeto em execução na sua máquina local para fins de desenvolvimento e teste.

### Pré-requisitos

Certifique-se de ter o [Node.js](https://nodejs.org/en) instalado.

### Instalação

1.  Clone o repositório:
    ```bash
    git clone [https://www.youtube.com/watch?v=w1RGT6FpXyY](https://www.youtube.com/watch?v=w1RGT6FpXyY)
    ```
2.  Entre no diretório do projeto:
    ```bash
    cd [nome-do-seu-projeto]
    ```
3.  Instale as dependências:
    ```bash
    npm install
    # ou yarn install
    ```
4.  Inicie o servidor de desenvolvimento:
    ```bash
    npm run dev
    # ou yarn dev
    ```

O projeto estará acessível em `http://localhost:5173`.
